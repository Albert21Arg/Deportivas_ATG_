# Frontend

Interfaz web para SuperAdmin, Admin y consulta de torneos.

- `src/components/`: componentes reutilizables.
- `src/pages/`: vistas de autenticación, torneos, equipos, partidos y tablas.
- `src/layouts/`: estructuras de navegación y paneles.
- `src/services/`: cliente de la API y autenticación.
- `src/hooks/`: lógica reutilizable de la interfaz.
- `src/context/`: sesión, usuario y permisos.
- `src/types/`: contratos de datos compartidos.
- `src/utils/`: utilidades de presentación.
- `src/styles/`: estilos globales.
- `src/assets/`: recursos estáticos.
